# 万能视频播放器（Universal Player）

基于 **PySide6 + VLC(libVLC)** 的桌面视频播放器。借助 VLC 解码内核，支持几乎所有音视频封装与流媒体协议——真正的"万能"。

## 核心特性

- **万能解码**：mp4 / mkv / avi / rmvb / wmv / flv / ts / webm / mov … 以及 `rtsp://` `rtmp://` `http(s)://` `mms://` `udp://` 等网络流。
- **AI 字幕（本地离线）**：一键从视频人声自动生成字幕（Whisper 语音识别），支持多语言翻译（Argos 离线翻译包 / Whisper 内置译英），生成后自动挂载并与播放同步展示；可输出原文 / 译文 / 双语三种 SRT。全程本地运行，无需任何 API key。
  - **分段并行识别**：长片按时间切段、多实例同时识别再合并时间轴，1.5 小时的长片可提速约 2 倍（实际取决于核数与内存）。
  - **后台化**：点「开始生成」后设置界面立即关闭，任务在后台跑，进度显示在状态栏；可继续播放/换片，也可随时取消。
  - **默认中文识别**：源语言默认中文，改过的配置会自动记住。
- **字幕同步校正**：字幕快了/慢了随时用 `G`（延后 50ms）/ `H`（提前 50ms）微调，`Ctrl+G` 精确输入毫秒，`Ctrl+Shift+G` 归零；状态栏常驻显示当前偏移；偏移**按片记忆**，下次打开自动套用；调准后可一键**写入 SRT 文件**永久生效（原文件自动备份 `.bak`）。
- **字幕即开即显**：打开视频立刻挂同名字幕，不会拖到几秒后才出现；挂上自动选中该字幕轨，避免"挂了但画面不显示"。
- **播放列表**：打开文件 / 文件夹（递归收集）、拖拽加入、双击播放、循环模式（顺序 / 单曲 / 列表 / 随机）。
- **播放控制**：播放/暂停、停止、上一首/下一首、进度拖动、音量、静音、**倍速 0.25x–4x**。
- **字幕 / 音轨**：加载外部字幕、切换内嵌字幕轨、字幕延迟微调；切换音轨。
- **画面**：画面比例（原始/16:9/4:3/21:9/填充）。
- **截图**：一键保存当前帧到截图目录（PNG/JPG）。
- **A-B 循环**：设定起止点循环播放片段。
- **记忆续播**：关闭时记录进度与播放列表，下次启动自动续播（可在设置中关闭）。
- **最近播放**、**窗口置顶**、**全屏**、**拖拽播放**、丰富**快捷键**。

## 环境依赖

- Python 3.13+
- 依赖：`PySide6`、`python-vlc`（见 `requirements.txt`）
- **必须**：本机安装 [VLC 播放器](https://www.videolan.org/)（提供 `libvlc` 解码内核）。
  - Windows 默认从 `PATH` / 注册表定位 VLC；若想免安装分发，把 VLC 安装目录下的
    `libvlc.dll`、`libvlccore.dll`、`plugins/` 复制到 exe 同目录即可。

## AI 字幕（识别人声 + 翻译）

菜单入口：**视频 → AI 字幕：识别人声并翻译…**（快捷键 `Ctrl+B`）。

工作流程：`Whisper 识别 → （可选）翻译 → 生成 SRT → 自动挂载到播放器同步展示`。

- **识别模型**（faster-whisper，CTranslate2 量化版，CPU 即可跑）：

  | 模型 | 体积 | 说明 |
  |------|------|------|
  | tiny | 75MB | 最快，实时率约 0.4x（CPU），质量一般 |
  | base | 145MB | 快 |
  | small | 480MB | **推荐**，质量/速度均衡 |
  | medium | 1.5GB | 更准，慢 |
  | large-v3 | 3GB | 最准，建议有显卡 |

- **翻译**：
  - 目标语言=英语 → 直接用 Whisper 内置译英（零额外依赖）；
  - 其他语言 → Argos 离线翻译包（每个语言对约 20-80MB，首次自动下载，之后永久离线）。
- **分段实时出字幕（默认开启，60 秒一段）——保证字幕一直存在**：
  按固定时长把片子切成小段**顺序**识别：**第 1 段跑完就立刻挂上字幕**，之后每段完成都会刷新一次画面上的字幕，
  所以从第一分钟起字幕就一直在，不用等整片跑完。段长可选 30 / 60 / 120 秒（默认 60）。
  - 实现要点：只对**当前段**做识别，识别完把结果并进累计时间轴并**原地覆盖**同一份实时 SRT；
    挂载时对同一路径重新挂一次——libVLC 3.x 对同路径不去重，会重新读取更新后的内容（已实测确认）。
  - 节流：libVLC 3.x 无法移除字幕轨，所以只有「已挂字幕覆盖不到 当前播放位置 + 30 秒」时才重挂，
    避免每段都多一条轨；全部识别完成后重开一次媒体挂完整字幕，轨道清零。
  - 音轨只抽一次：整条片子先一次性抽成 16k 单声道 wav，逐段按样本切片，省掉上百次 ffmpeg seek。
- **分段并行**（追求整片最快时用）：只在**取消**上面的「分段实时出字幕」后生效——

  | 选项 | 说明 |
  |------|------|
  | 自动（推荐） | 按 CPU 核数自动定段数（8 核 → 4 段），5 分钟以内的短片自动走单路 |
  | 不分段 | 最省内存（单实例，约 1 份模型内存） |
  | 2 / 4 / 8 段 | 手动指定；每段各占一份模型内存 |

  原理：把音频按时间等长切段（段间留 1 秒重叠防止切词），每段用独立 Whisper 实例并行识别，
  再把时间戳补偿并合并成一份 SRT。实测（8 核，tiny，同一段真实语音）：单路 144s → 4 段并行 117s，
  约 1.2~1.8 倍——单路已用掉一半核，瓶颈在内存带宽，不是核数。
  内存吃紧（如 8GB 笔记本）建议选 2 段或不分段。
- **识别模式（温度回退）——真正的提速开关**：

  | 模式 | 说明 |
  |------|------|
  | 快速（默认） | 只用 temperature=0 解码一次。实测同一段 200 秒讲课语音：**46 秒**（4.4x 实时） |
  | 稳健 | 难句自动升温重试（faster-whisper 默认）：同段 **252 秒**（0.79x 实时），慢 5.5 倍 |

  Whisper 默认会在低置信度句子上把温度从 0 逐档升到 1 反复重解码，这是长片最大的耗时黑洞；
  清晰语音关掉它识别质量几乎不变，只有音频很嘈杂时才建议选「稳健」。
- **耗时参考**（small 模型 + CPU 半核，1.5 小时讲课片）：单路约 20~30 分钟，4 段并行约 10~15 分钟；
  换 base 约快 2 倍，换 tiny 约快 4 倍；有 N 卡把「运行设备」设为 cuda 可再快一个数量级。
- **输出**：默认保存在视频同目录，`原名.srt` / `原名.译文.srt` / `原名.双语.srt`；双语模式原文在上译文在下。
- **模型管理**：`视频 → 管理 AI 模型…` 可预下载模型与语言包、查看已装清单。
- **模型保存位置**：程序目录 `models/`，随程序分发即可实现绿色离线版。
- 模型下载默认走 `hf-mirror.com` 国内镜像（可用环境变量 `HF_ENDPOINT` 覆盖）。

AI 字幕链路验证：`python verify_ai_subtitle.py`（7 组用例：依赖 / 模型 / 识别 / 翻译 / 译英 / SRT 读写 / 播放器挂载同步）。

## 运行（开发模式）

```bash
pip install -r requirements.txt
python main.py                 # 启动
python main.py "电影.mkv"      # 直接打开文件
python main.py "http://.../live.m3u8"   # 直接打开网络流
```

## 打包为 exe

```bash
pip install pyinstaller
pyinstaller build.spec
# 产物：dist/万能视频播放器/  （onedir 文件夹模式，无控制台，已禁用 UPX）
```

> 打包基线参考：`console=False` + `upx=False`；若运行异常可查看同目录 `_launch.log`。
> 要让分发包自带解码能力，把 VLC 的 `libvlc.dll` + `libvlccore.dll` + `plugins/` 一起放进 `dist/万能视频播放器/`。

## 端到端验证（可选）

仓库自带 `verify_playback.py`，用**真实 VLC 引擎**验证解码核心：多容器解码、时长、
分辨率/编码、音轨与字幕轨枚举、seek、倍速、音量、外部字幕加载、截图。

```bash
# 本机已安装 VLC 时直接跑
python verify_playback.py

# 便携版 VLC：用环境变量指向含 libvlc.dll 的目录
set VLC_DIR=D:\apps\vlc-3.0.24
python verify_playback.py

# 有显示的本机：启用真实渲染并验证截图
set VLC_HEADLESS=0
python verify_playback.py
```

沙盒（VLC 3.0.24 + mp4/mkv/ts 三种容器）实测结果：

| 容器 | 时长 | 分辨率 | 音频编码 | seek | 倍速 | 外部字幕 |
|------|------|--------|----------|------|------|----------|
| test.mp4 | 6000ms | 640x360 | AAC | OK | OK | OK |
| test.mkv | 6023ms | 640x360 | AAC | OK | OK | OK |
| test.ts  | 6660ms | —（见限制） | MPEG audio | OK | OK | OK |

另有 `verify_ui.py`：无显示环境下用 Qt offscreen 渲染并 `grab()` 截图，验证 UI 布局与降级。

## 已知限制

- 无显示环境（沙盒/CI）走 `--vout=dummy`，**截图**依赖真实渲染窗口、**音量**依赖真实音频设备，两者会标记为 SKIP，需在本机有显卡/声卡时复核。
- MPEG-TS 等慢解析容器在 dummy 渲染下可能取不到分辨率（解码/拖动/时长均正常），程序内置 3 秒延迟重试机制覆盖这类情况。
- 帧率(fps)读不到时状态栏自动省略该项（取决于 python-vlc 的 MediaTrack 结构版本）。

## 目录结构

```
universal_player/
├── main.py               # 入口
├── main_window.py        # 主窗口 + 全部交互

├── playlist.py           # 播放列表模型
├── settings.py           # 配置 / 续播历史（JSON 持久化）
├── ai_subtitle.py        # AI 字幕引擎（Whisper 识别 + Argos 翻译 + SRT 读写）

├── build.spec            # PyInstaller 打包（含 exe 图标）
├── verify_ui.py          # UI 构建回归（offscreen 截图）
├── verify_playback.py    # 播放链路端到端验证
├── verify_ai_subtitle.py # AI 字幕链路端到端验证
├── verify_subtitle_swap.py # 字幕挂载/替换/释放回归
├── tools/                # 图标生成、打包、各类冒烟与性能验证脚本
└── requirements.txt
```
